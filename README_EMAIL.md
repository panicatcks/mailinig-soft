# Рассылка писем по HTML-шаблону (SMTP Timeweb)

Скрипт: `send_email.py`  
Поддерживает:
- отправку HTML-шаблона с встраиванием локальных картинок (`cid`);
- загрузку получателей из `.xlsx`, `.csv`, `.txt`;
- выбор колонок Excel (`A,B,C,D...`) для персонализации;
- лимиты отправки в минуту и в сутки.

## 1) Установка зависимости для Excel

```bash
python3 -m pip install openpyxl
```

## 2) Проверка без отправки (рекомендуется)

```bash
cd "/Users/panicatcks/Downloads/Дмитриев"
python3 send_email.py \
  --template "./Нефтегаз/landing_oil_gas.html" \
  --to-file "./База СЗФО Дмитриев (1).xlsx" \
  --xlsx-email-col G \
  --xlsx-fields A,B,C,D \
  --xlsx-start-row 2 \
  --limit-per-minute 20 \
  --limit-per-day 300 \
  --dry-run
```

## 3) Реальная отправка

```bash
python3 send_email.py \
  --template "./Нефтегаз/landing_oil_gas.html" \
  --to-file "./База СЗФО Дмитриев (1).xlsx" \
  --xlsx-email-col G \
  --xlsx-fields A,B,C,D \
  --xlsx-start-row 2 \
```

## 4) Как работают поля из Excel

Если указать:
- `--xlsx-fields A,B,C,D`

то в шаблоне можно использовать:
- `{{A}}`, `{{B}}`, `{{C}}`, `{{D}}`
- также доступны `{{COL_A}}`, `{{COL_B}}` и т.д.

Можно подставлять и в тему письма:
- `--subject "Коммерческое предложение для {{B}}"`

## 5) Важные параметры

- `--xlsx-email-col G` — колонка, где email.
- `--xlsx-start-row 2` — строка начала чтения (обычно после заголовка).
- `--limit-per-minute 20` — максимум 20 писем за 60 секунд.
- `--limit-per-day 300` — максимум 300 писем в текущие сутки.
- `--state-file .send_email_state.json` — файл, где хранится дневной счётчик.
- если в одной ячейке несколько email через запятую/точку с запятой — все будут учтены.
- позиция отправки (курсор и последняя строка Excel) сохраняется в `state-file`, чтобы продолжить со следующей строки на следующий день.

## 6) Если ошибка по колонке

Если в указанной колонке email не найдены, скрипт покажет подсказку с вероятными колонками (например `G`).

## 7) Графический интерфейс (GUI)

Запуск:

```bash
cd "/Users/panicatcks/Downloads/Дмитриев"
python3 email_gui.py
```

В интерфейсе можно:
- выбрать шаблон и Excel;
- включить автоподбор HTML по базе/листу (или нажать `Авто по базе`);
- задать колонку email и поля `A,B,C,D`;
- включить режим `Шаблон по колонке вида рассылки` и указать колонку (например `P`);
- задать фильтр по виду: `ALL` (все) или, например, `ГВС` или `ГВС,Море`;
- при тестах на один адрес включить `Разрешить повторы email`, чтобы ушло несколько писем на один ящик;
- выставить лимиты в минуту/сутки;
- запустить проверку (`Проверить`) или реальную отправку (`Отправить`);
- на вкладке `Тест` указать email и отправить тестовое письмо только на него;
- сохранить настройки для следующих рассылок.

Пример для вашей таблицы: если в колонке `P` значения `ГВС`, `Пищевые`, `Море`, то скрипт автоматически возьмёт соответствующий HTML-шаблон из одноимённых папок.
Если поле `HTML шаблон` пустое — шаблон подставится автоматически при запуске.
Если суточный лимит уже исчерпан, скрипт вернёт ошибку вида `ratelimit wait 0d 12h 34m 56s`.

Чтобы письма реже попадали в спам:
- для домена отправителя должны быть настроены SPF + DKIM + DMARC;
- отправляйте постепенно (не резко большими объёмами с нового ящика/домена);
- в письма автоматически добавляются `List-Unsubscribe`, `Message-ID`, `Date` и `Precedence: bulk`.

Трекинг открытия через Mailroute Hub:
- откройте вкладку `Хаб` и заполните `Hub URL`, `Hub Conn ID`, `Hub Secret`;
- нажмите `Проверить Hub` и `Проверить пиксель` для быстрой проверки;
- если у Hub временно проблемный сертификат, включите `Игнорировать SSL ошибки (тест)`;
- в письмо добавится 1x1 пиксель, при открытии Hub получит событие `mail_open`;
- на стороне Hub используется endpoint `GET /api/v1/public/mail-open.gif`.
- после завершения отправки программа отправляет в Hub отчет `mailing_campaign` (campaign_id, success/failed, started_at/finished_at).
- в Hub вкладке `Рассылки` можно кликнуть по `Campaign ID` и провалиться в детализацию открытий.
